Principais categorias do HTML5:

-Metadata Content

-Flow Content

-Sectioing Content

-Heading Content

-Phrasing Content

-Embedded Content

-Interactive Content


Metadata Content

<title> Informa o Titulo

<meta> Definir Codificação

<link> e <style> Importa CSS

<script> Configurar o comportamento da página (javascript)


Flow Content

Representa a maior parte dos elementos usados no body

<div> Caixa de divisão genérica, serve para agrupar "pedaços" de códigos.

<p> Para colocar parágarfos na minha página.

<section> Agrupa conteúdos que partilham do mesmo assunto ou idéia

<article> Conteúdo independente e completo por si só (faz sentido sozinho)

<img> Mostra uma imagem, foto, desenho, etc. (não precisa de tag de fechamento)

<form> Criar formulários, o usuário poderá digitar dados, enviar mensagens, ou fazer login.


Sectioning Content

Organizar grandes áreas do documento

<Section> Agrupa conteúdos que partilham do mesmo assunto ou idéia.

<article> Conteúdo independente e completo por si só (faz sentido sozinho).

<Aside> Serve para guardar o conteúdo segundário/lateral (links relacionados, anúncios, biografia e etc).

<Nav> Agrupa links de navegação


Heading Content

h1, h2, h3, h4, h5 e h6 -> Para adicionar títulos e subtítulos

<hgroup> Serve para agrupar elementos de títulos, exemplo:

Aprenda HTML

Senai Americana


Phrasing Content

Elementos que marcam textos ou partes de texto

<span> Um bloco genérico, não muda nada sozinho. Serve para agrupar pedaços de texto e aplicar CSS ou funções com JavaScript.

<a> Cria um link para direcionar o seu usuário para outra página, utilizando o atributo href. Exemplo: Clique aqui para ir ao site do bitcoin

<strong> Deixa uma parte do textlo em negrito

<em> Deixa uma parte do texto em itálico

<mark> Adiciona um marcador em uma parte do texto

<img> Mostra uma imagem, foto, desenho, etc. (não precisa de tag de fechamento)


Embedded Content

<img>Mostra uma imagem, foto, desenho, etc. (não precisa de tag de fechamento)

<video> Adiciona um video direto no site (pode mostrar botões de play e pause)

<canvas> Criar uma tela em branco, podera ser mudada pelo JavaScript

<svg> Desenha gráficos baseados em vetores

<iframe> Coloca outra página inteira dentro do seu website (muito usado para adicionar mapas e vídeos de outros sites)


Interactive Content

<a> Cria um link para direcionar o usuário para outra pagina, utilizando o atributo href

<button> Criar um botão clicável. Exmplo:

<input> é usado para receber dados. Dentre os dados aceitos estão:

type="text": Campo de texto curto.
type="password": Oculta os caracteres digitados.
type="email": Valida se o dado possui formato de e-mail.
type="number": Permite a entrada de números.
type="checkbox": Caixa de marcação.
type="radio": Permite uma escolha única.

Observação: type é um atributo da tag <input>, e não uma tag. A tag <input> não precisa de fechamento.

< select> Cria uma caixa de seleção em formato de lista suspensa(dropdown)

<textarea> Cria uma "caixa" com várias linhas, serve para textos longos, comentários, mensagens e biografia

Listas em html

Lista não ordenada (ul), exemplo:

  • Item 1
  • Item 2
  • Item 3

Lista ordenada(ol), exemplo:

  1. Item 1
  2. Item 2
  3. Item 3
